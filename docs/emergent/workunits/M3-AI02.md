# M3-AI02 — Synthetic report drafting

Status: implementation in progress; CI and independent review pending. PR #155.

Predecessor M3-STT01 PR #154 merged at `d4fa4b5d20dc2a5a135fa3f9d76d42f9a3da4595` with six green CI checks and clean review.

## Implemented scope

- Offline fictional-evidence report proposal builder with source IDs, missing-source warnings, and `REFERENCED_NOT_VERIFIED` marker.
- Therapist-only report editor controls: choose section, generate, edit, discard, or explicitly insert a synthetic passage into an editable report. Insertion uses existing optimistic concurrency/autosave; no silent persistence before insertion.
- Browser regression of generate/discard/insert/save. No external calls or new server routes, migrations, approval, signing, or family release.
- Server already supplies report evidence only after actor/tenant/child authorization and a `canEdit` flag; this client-only assistant never accepts a tenant or source from the caller.

## Boundaries and remaining work

This is deterministic template assistance, **not** an LLM service. No clinical claims are validated, no real patient processing is enabled, and the existing disabled AI provider remains unchanged. External report-generation providers, model prompts, signed human-acceptance provenance and patient-data use require separately approved D2/D3/D11/PD policy and later workunits. CI and final code review must qualify the exact implementation HEAD before merging.
