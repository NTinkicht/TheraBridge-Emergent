# M3-AI02 — AI-Assisted Clinical Report Drafting

Status: PLANNING CHECKPOINT — NOT IMPLEMENTED / NOT TESTED.

Predecessor: M3-STT01 PR #154 merged at `d4fa4b5d20dc2a5a135fa3f9d76d42f9a3da4595` (six green jobs and clean exact-head independent review).

## Intent

Implement a controlled, clinician-reviewed **synthetic-only** draft-report workflow that uses fictional session inputs. Preserve clinical source attribution, explicit uncertainty, tenant isolation, and a clear distinction between an AI-proposed draft and a clinician-authorized clinical report.

## Proposed scope for implementation review

1. Construct report-drafting inputs exclusively from explicitly selected fictional/synthetic session material in the development adapter. Do not ingest live patient notes or real audio.
2. Emit structured draft sections with source pointers, uncertainty markers, version/provenance metadata, and safe error states. Generated content must never be represented as verified clinical findings.
3. Provide therapist-only draft preview, edit, reject, regenerate, and explicit human acceptance controls. No automatic publication, family release, signing, or persistence as a final clinical record.
4. Enforce server-side tenant and therapist access checks for every draft operation, including negative cross-tenant tests. Respect revocation and existing protected report-release policy.
5. Add unit, integration, and browser regression coverage for happy paths, missing/contradictory sources, failure recovery, prompt injection, and rejection. Validate required CI and independent review on the exact implementation head.

## Safety and policy boundary

Synthetic-only implementation is authorized. External model/provider calls, patient-data processing, live clinical activation, and family release remain disabled unless separately approved through applicable D2/D3/D11/PD and clinical policies. This workunit does not grant those approvals.

## Checkpoint acceptance

This initial PR establishes work order and reviewable boundaries only. It must not be merged as an implementation completion without code, tests, all six CI jobs, exact-head independent review, and required handover updates.
