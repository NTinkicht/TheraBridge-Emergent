## Implementation scope

1. Introduce a normalized read-only source-reference contract for the synthetic report-drafting and home-plan candidate flows, including center/child/plan/report/version/goal or template identity, source availability and provenance version.
2. Make source references navigable and understandable to the authenticated clinician in the same tenant/child scope; never expose cross-tenant or unassigned child sources through an identifier, log or UI.
3. Detect removed, superseded, stale, conflicting, missing or unverified fictional evidence before a candidate is adopted. Distinguish referenced from clinically verified facts; never silently promote generated text to clinical truth.
4. Require existing optimistic version and therapist assignment checks to remain authoritative. Synthetic source labels are not authorization tokens.
5. Add negative tests for cross-tenant/child source manipulation, stale revisions, missing evidence, tampered references, prompt injection, revocation and graceful failure. Preserve existing six CI jobs.

## Governance and limits
